# Code of Conduct

Everyone taking part in Claude Chat Backup — issues, pull requests, discussions and any other
project space — is expected to keep collaboration respectful, constructive and welcoming.

Harassment, discrimination, personal attacks, doxxing, publishing other people's private
information and deliberate disruption are not accepted. Disagreement about architecture, design
or code is welcome when it stays focused on the work and on evidence.

Maintainers may edit, hide or remove contributions that violate these expectations, and may
temporarily or permanently restrict participation. Report concerns privately to the repository
owner through the contact options on the maintainer's
[GitHub profile](https://github.com/claudneysessa).
